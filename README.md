## About
In this assignment I practised basic Python: if/else for a grade checker, a dictionary with a menu to add, update and show student grades, and file handling to write a file and read it back.

## Files in this folder
- grade_checker.py - task 1, takes a score and prints the grade (A, B, C, D or F)
- student_grades.py - task 2, menu to add a student, update a grade and show all grades
- write_file.py - task 3, creates serversinfo.txt and writes server names in it
- read_file.py - task 4, reads serversinfo.txt with read() and prints it
- serversinfo.txt - file created by task 3
- Python_and_Bash_AdityaKundu.docx - screenshots and explanation of every task

## How to run
Open a terminal inside this folder and run:
```
python grade_checker.py
python student_grades.py
python write_file.py
python read_file.py
```
Run write_file.py before read_file.py, because read_file.py reads the file made by write_file.py.
